  <files>ingest/__init__.py</files>
  <behavior>
    - to_utc_iso(value: int | str, source_format: str = "unix_ms") -> str handles three formats:
      * "unix_ms": value is int milliseconds since epoch -> datetime.fromtimestamp(value/1000, tz=timezone.utc).strftime(...)
      * "unix_s": value is int seconds since epoch
      * "gdelt": value is str in YYYYMMDDHHMMSS format
      * Output always: "YYYY-MM-DDTHH:MM:SS.ffffffZ"
    - get_connection(db_path: str | Path) -> sqlite3.Connection opens connection, sets WAL + busy_timeout + synchronous=NORMAL, returns connection
    - Uses datetime.now(timezone.utc) only (never datetime.utcnow() — deprecated Python 3.12)
    - Type hints on every function, German docstrings, English comments
  </behavior>
  <action>
    Create ingest/__init__.py.
    Import: from datetime import datetime, timezone; import sqlite3; from pathlib import Path; import re

    Implement to_utc_iso():
      - source_format="unix_ms": dt = datetime.fromtimestamp(int(value) / 1000, tz=timezone.utc)
      - source_format="unix_s": dt = datetime.fromtimestamp(int(value), tz=timezone.utc)
      - source_format="gdelt": dt = datetime.strptime(str(value), "%Y%m%d%H%M%S").replace(tzinfo=timezone.utc)
      - Return dt.strftime("%Y-%m-%dT%H:%M:%S.%f") + "Z"
      - Raise ValueError for unknown source_format

    Implement get_connection():
      - conn = sqlite3.connect(str(db_path))
      - conn.execute("PRAGMA journal_mode=WAL;")
      - conn.execute("PRAGMA busy_timeout=10000;")
      - conn.execute("PRAGMA synchronous=NORMAL;")
      - return conn

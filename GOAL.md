# GOAL.md

## Active Goal

Define empirical research scope before H2/H3 implementation.

## Why This Goal Is Active

H2 and H3 are currently blocked by research-design decisions, not code volume.
The event catalog, event windows, RCP treatment, and whale classification rules
must be fixed before CAR, lead-lag, or Granger code is written.

## Completion Criteria

- Research objective and hypotheses are documented.
- Event inclusion and exclusion rules are documented.
- Event windows are defined before analysis.
- Whale method uses dataset-relative tiers, not arbitrary thresholds.
- RCP is documented as a polling signal unless a tested probability
  transformation is added later.
- Agents, MCP, and ML remain out of scope until deterministic outputs exist.

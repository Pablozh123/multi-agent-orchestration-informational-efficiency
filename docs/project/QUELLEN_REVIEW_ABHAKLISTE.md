# Quellen-Review — einfache Abhakliste

So einfach wie moeglich gemacht. Ich habe pro Quelle die belegte Aussage und die
Fundstelle vorbereitet und die inhaltliche Deckung vorgeprueft. **Dein Teil pro
Quelle (~30 Sekunden):** Link oeffnen → mit Strg+F den fettgedruckten Begriff
suchen → kurz schauen ob die Stelle die Aussage stuetzt → Haken setzen. Der Haken
ist deine Bestaetigung „gelesen und geprueft" (Teil der Eigenstaendigkeitserklaerung).

Danach im Ledger (`data/results/thesis_source_review_ledger_FILLED_DRAFT.csv`) die
Spalte `final_citation_ready` auf TRUE setzen — oder du hakst hier ab und ich
uebertrage es.

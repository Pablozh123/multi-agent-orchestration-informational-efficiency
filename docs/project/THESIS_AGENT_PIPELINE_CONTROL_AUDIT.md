## Use Rule

Nutze dieses Audit nur als Future-Work-Kontrolle. Vor Aktivierung braucht jede Rolle ein separates genehmigtes Goal, bounded inputs, Tests, `llm_audit_log`, max 50 rows by default und eine erneute Review der blockierten Aktionen. Bis dahin gelten: keine Runtime-Agenten, kein MCP, kein Model Routing, keine LLM-Metriken, kein Rohdaten-Prompt, keine Wallet-Adress-Exposition by default und keine Trading-Pfade.

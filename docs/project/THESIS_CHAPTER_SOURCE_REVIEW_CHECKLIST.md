# Chapter Source Review Checklist

Diese Checkliste macht aus dem H1-H2-H3 Chapter Handoff konkrete manuelle Abnahmeschritte. Sie liest keine Quelleninhalte, berechnet keine Kennzahlen, promotet keinen Quellenstatus und aktiviert keine Runtime-Agenten. Sie ist eine Schreib- und Review-Kontrolle fuer den BA-Draft, nicht die finale Quellenfreigabe.

## Use Rule

Nutze die Checkliste beim Schreiben und Kontrollieren von H1, H2 und H3. Jeder Kapitelteil muss Evidence IDs, Literatur IDs, Artefakte, kuratierte Tabellen/Figuren, Limitationen und Source-Review-Gates sichtbar halten. Keine finale Zitation ohne manuelle Ledger-Review. Keine Rohartefakt-Dumps, keine Quellenstatus-Hochstufung, keine Runtime-Agenten, kein MCP, kein Model Routing, keine LLM-Metriken, keine Wallet-Adress-Exposition und keine Trading-Pfade.

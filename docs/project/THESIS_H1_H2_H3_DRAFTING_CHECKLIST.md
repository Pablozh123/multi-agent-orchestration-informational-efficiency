## Use Rule

Nutze diese Datei als Schreibreihenfolge fuer H1, H2 und H3. Jeder Abschnitt muss Evidence IDs, Literatur IDs, deterministische Artefakte, kuratierte Tabellen/Figuren, Limitationen, blockiertes Wording und Source-Gate sichtbar halten. Keine neue Kennzahl, keine Rohartefakt-Dumps und keine finale Zitation, solange Source Review offen ist. Vor dem Citation Gate muss der Manual Source Review Follow-up Overview-/Ledger-Abgleich sichtbar bleiben. Agenten bleiben Future Work: keine Runtime-Agenten, kein MCP, kein Model Routing, keine LLM-Metriken, keine Wallet-Adress-Exposition und keine Trading-Pfade.

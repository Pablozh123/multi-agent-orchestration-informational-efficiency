## Use Rule

Arbeite die Worksheets in der Reihenfolge H1, H2, H3 und danach TOTAL-Rebuild ab. Jede Zeile braucht Page-/Section-Note, Claim-Support, Blocked-Wording, Citation-Use und Reviewer-Metadaten. H2 behaelt die Kausalclaim-Grenze; H3 behaelt Granger-Grenze und Wallet-Grenze. Keine finale Zitation, keine Quellenstatus-Hochstufung, keine Wallet-Adressen, keine Trading-Claims, keine Profitabilitaetsclaims und keine Runtime-Agenten.

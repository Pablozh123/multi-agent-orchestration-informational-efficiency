    - parse_prices(response: dict, market_id: str, token_id: str, fetched_at: str) -> list[dict]:
      * Takes raw CLOB API JSON response ({"history": [{"t": ..., "p": ...}, ...]})
      * fetched_at is the UTC ISO 8601 timestamp when the API was called (passed in, not generated inside)
      * Returns list of dicts, one per price row, with keys: price_timestamp, fetched_at, market_id, token_id, price, volume_24h, best_bid, best_ask
      * price_timestamp = to_utc_iso(row["t"], "unix_ms")
      * volume_24h, best_bid, best_ask are None (CLOB prices-history does not return these)
      * price = float(row["p"]) — must be in [0.0, 1.0] (Polymarket implicit probability)
      * Returns empty list if response["history"] is empty (resolved market + wrong fidelity case)
    - This function has no I/O — pure transformation. This is what tests mock.
    - Type hints on every parameter and return value
    - German docstring explaining look-ahead bias concern
  </behavior>

    triggering any network calls — no module-level side effects.

    After parse_prices, implement async fetch_polymarket_prices(token_id: str, fidelity: int = 1440) -> dict:

      - URL: "https://clob.polymarket.com/prices-history"
      - Params: {"market": token_id, "interval": "max", "fidelity": fidelity}

      - Returns (market_id, token_id) for the YES outcome token
      - Logs resolved IDs to console

    Implement async ingest_polymarket(db_path: Path = DB_PATH) -> int:
      - Calls resolve_token_id() to get current market_id and token_id
      - Records fetched_at = datetime.now(timezone.utc).strftime(...)

      - If response["history"] is empty: log warning, save response to data/polymarket_debug.json, return 0
      - Calls parse_prices(response, market_id, token_id, fetched_at)
      - Opens DB with get_connection(db_path)
      - Executes INSERT OR IGNORE for each row
      - conn.commit()
      - Returns number of rows inserted (using cursor.rowcount per INSERT)

    if __name__ == "__main__": asyncio.run(ingest_polymarket())
  </action>
